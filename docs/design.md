# TAILSPIN ゲーム設計メモ

この文書は戦闘と基礎システムの実装仕様です。追加した3勝先取・8ステージ・隕石・移動セーフゾーン・見た目の仕様は [ステージとシリーズの設計](stages-and-series.md) を参照してください。変更時は [`combat.ts`](../src/game/combat.ts)、[`engine.ts`](../src/game/engine.ts)、[`types.ts`](../src/game/types.ts) を正として更新します。

## 1. ゲームの中心

**攻撃で吹っ飛び率をため、しっぽで相手を押し出し、狭くなる足場に残る。**

参加者は標準24体で、1体をプレイヤーが操作し、23体をCPUが操作します。人間だけを狙う特別なターゲット指定はなく、CPU同士も交戦します。オンライン同期・ネットワーク通信はありません。

ラウンドの勝利条件は最後の生存者になることです。3勝先取では各ラウンドの勝者に1勝を与え、誰かが3勝するまで全員が復帰して続行します。全員が同じシミュレーション刻みで脱落した場合は引き分けになります。HP・残機・復活はなく、落下するとその試合から脱落します。被弾から8秒以内の落下は、最後に攻撃した参加者の撃墜として記録します。

キャラクターは球状の体、足、目、曲がったしっぽを組み合わせたオリジナル形状です。腕や人型の骨格を前提とせず、体の伸縮、足の動き、体の回転、しっぽの軌道でアクションを表現します。

## 2. 技とスタミナ

数値は秒・ワールド座標単位で管理します。「判定区間」は動作開始からの経過時間です。描画フレーム数ではなく、シミュレーションの時間で判定します。

| アクション   | 加算ダメージ | スタミナ | 判定区間           | 動作全体 | 基本ノックバック速度 | 判定半径 |
| ------------ | ------------ | -------- | ------------------ | -------- | -------------------- | -------- |
| 弱攻撃       | 7%           | 0        | 0.07〜0.16秒       | 0.32秒   | 3.6                  | 1.55     |
| しっぽスピン | 15%          | 25       | 0.19〜0.46秒       | 0.74秒   | 5.1                  | 2.20     |
| 空中攻撃     | 10%          | 10       | 0.07〜0.26秒       | 0.47秒   | 4.2                  | 1.80     |
| ローリング   | —            | 28       | 出だし0.25秒が無敵 | 0.52秒   | —                    | —        |
| ジャンプ     | —            | 0        | 地上でのみ開始     | 着地まで | —                    | —        |

弱攻撃は前方、しっぽスピンは全周、空中攻撃は前方を中心とした広い範囲に判定を持ちます。相手との高さの差も確認します。同じ攻撃IDでは同じ相手を複数回ヒットさせません。

地上の `J` は弱攻撃、`K` はしっぽスピンです。空中ではどちらも空中攻撃になります。空中ジャンプと空中ローリングはありません。スタミナが足りない行動は開始しません。

### スタミナ回復

最大値は100、回復速度は毎秒24です。消費する攻撃の後は0.75秒、ローリングの後は0.85秒の回復待ち時間があります。弱攻撃も回復開始を最低0.16秒遅らせます。しっぽスピン・ローリングの動作中は回復しません。

スタミナを使い切ってもジャンプと移動はできます。回転棒への対処手段を残しながら、連続ローリングや強攻撃の連打には制約を与えています。

### 無敵・隙・空中制御

ローリングの初速は9.7、開始0.27秒後から急減速します。無敵が終わった後も動作が続くため、終わり際は攻撃を受けます。通常の被弾後には0.46秒の無敵を付与し、多人数から連続して拘束され続ける状況を抑えます。

地上歩行速度は4.5、通常ジャンプの初速は8.2、重力は21です。空中では方向入力で徐々に軌道を修正できます。場外に出た座標を足場の内側へ強制的に戻す処理はなく、床が存在しなければ落下します。

## 3. 吹っ飛び率

被弾後の蓄積ダメージを用いて、水平の初速度を次の式で求めます。

```text
吹っ飛び初速度 = 技の基本速度 × (1 + 被弾後の蓄積ダメージ / 110)
```

例えば同じ技でも、被弾後の蓄積が0%なら基本速度の1倍、110%なら2倍、220%なら3倍になります。実際の移動距離は着地、減速、空中制御、障害物との接触でも変わります。上方向の速度も与えるため、単純に床の上を滑るだけのノックバックにはなりません。

蓄積の上限は999%です。回転棒・バンパー・スターにも同じノックバック式を適用します。序盤に耐えられた障害物が、高い蓄積では撃墜につながります。

## 4. スターとしっぽの打ち返し

スターはアリーナの2地点から拾えます。1体が持てるのは1個で、拾われた地点は10秒後に再出現します。その足場が崩れた後は出現しません。

`E` で向いている方向へ投げます。投げる動作には0.28秒の隙があり、投げた瞬間に追加の近接攻撃判定は発生しません。通常の投擲速度は8です。外周から飛来するスターもあり、そちらの初速は5.8です。

### 反射の成立条件と結果

しっぽスピンの**有効判定中**に、しっぽの範囲と高さに入ったスターを反射します。予備動作中・動作終了後・空中攻撃では反射しません。

- スターの所有者と色が、打ち返した参加者に変わる。
- 近くに相手がいる場合は、その相手へ打ち返す補助を行う。範囲内に相手がいなければ逆方向に返す。
- 速度を「現在速度 × 1.2 ＋ 1」に増加させる。上限は17。
- 有効時間を5秒に更新する。
- 同じスピンで同じスターを繰り返し反射しない。
- 現在の所有者には当たらず、命中・撃墜の記録は新しい所有者に帰属する。

スターのダメージは初期12%、反射ごとに3%加算し、最大24%です。基本ノックバック速度は5.5で、反射ごとに1加算し、最大8.5になります。

## 5. アリーナと時間進行

スカイ・スピナーの初期の床は **11×11枚**、タイル幅1.8、全体幅19.8です。ほかに十字・八角形・円環・ひし形・横長の足場があり、安全地帯ステージのみ15×15枚です。以下の崩落時間はLEVEL 1の基本値です。床の支持判定はタイルごとに行い、崩落開始時点でそのタイルからの支持を失います。落ちる床のアニメーションは、その後も続きます。

| 経過時間 | 崩落後の床 |
| -------- | ---------- |
| 0〜30秒  | 11×11      |
| 30秒     | 9×9        |
| 55秒     | 7×7        |
| 80秒     | 5×5        |
| 105秒    | 3×3        |
| 130秒    | 中央1枚    |
| 155秒    | 中央も崩落 |

各崩落の5秒前に対象の外周が点滅します。試合開始前の3秒カウントダウンと一時停止中の時間は、この経過時間に含めません。

中央の棒は高さの低い両端付きの回転棒です。角速度は0.72 rad/sから徐々に増加し、最大1.27 rad/sになります。床が狭くなると棒も短くなります。ジャンプで飛び越えるか、ローリングの無敵時間を合わせて通過できます。棒への被弾は7%です。

ほかにバンパー2基とジャンプ床2枚を配置しています。バンパーは外向きに弾いて5%を加算し、ジャンプ床は通常より高く跳ね上げます。中央の支柱には接触判定があり、地上で通り抜けることはできません。

## 6. CPU

CPUも同じ移動・スタミナ・攻撃・被弾処理を使います。主な判断は次のとおりです。

- 近い生存者を相手に選ぶ。
- 外周の危険を予測し、崩落予告が出たら内側へ戻る。
- 中央の支柱やバンパーを避ける。
- 回転棒の少し先の位置を読んでジャンプする。
- スタミナが少なければ間合いを取る。
- 距離に応じて弱攻撃・しっぽスピン・投擲を選ぶ。
- 相手の攻撃や飛来スターに対して、回避・打ち返しを試みる。

「やさしい / ふつう / つよい」は判断間隔、移動速度、回転棒の予測時間、反射の選択に差を付けています。完全回避・完全反射を保証するCPUではありません。

## 7. コードの責務

| 層               | ファイル                               | 責務                                                                                      |
| ---------------- | -------------------------------------- | ----------------------------------------------------------------------------------------- |
| ゲームループ     | `src/App.tsx`                          | 1/60秒の固定刻みでシミュレーションを進め、RAFで描画。ReactにはHUD用の状態を低い頻度で通知 |
| ゲーム状態       | `src/game/types.ts`                    | 状態・入力・イベントの型と初期設定                                                        |
| シミュレーション | `src/game/engine.ts`                   | 物理、CPU、床、アイテム、勝敗。DOMや描画APIには依存しない                                 |
| 技データ         | `src/game/combat.ts`                   | 技の時間、威力、範囲、消費量、吹っ飛び式                                                  |
| 描画             | `src/game/renderer.ts` / `meshes.ts`   | 3Dモデルと演出。共有ジオメトリ・マテリアル、簡易影、カメラに合わせた2Dラベル              |
| 入力             | `src/game/input.ts`                    | キーボード・タッチ・ゲームパッドから移動ベクトルと押下イベントを作る                      |
| 音               | `src/game/audio.ts`                    | ゲームイベントを効果音に変換。24体の接触音が過密にならないよう間引く                      |
| UI               | `src/ui/GameUI.tsx` / `src/styles.css` | ロビー、HUD、一時停止・結果、操作説明、仮想コントローラー                                 |

乱数はシード付きで、同じシードと入力列なら同じシミュレーションを再現できます。通常のスタート・再挑戦では新しいシードを選びます。ロジックは描画なしで実行できるため、戦闘や崩落の検証にブラウザーは必須ではありません。

描画では実際の3Dメッシュを使用します。24体分の影を毎フレーム別描画する方式は採用せず、簡易の接地影と共有アセットを使います。WebGL 2が前提です。浮動小数点レンダーターゲットが使えない環境では環境光の方式を切り替えます。

## 8. 検証と公開

[`tests/engine.test.ts`](../tests/engine.test.ts) では、24体の初期配置、カウントダウン、一時停止、乱数再現性、勝敗・引き分け、空中ジャンプ不可、スタミナと回避無敵、蓄積ノックバック、スピンの単一ヒット、反射・所有権、投擲、外周の予告と床支持、最終崩落を検証します。

UIとGPU描画の確認にはPlaywrightを使います。`pnpm check` は型・シミュレーション・ビルドまでのコマンドで、ブラウザー確認は `pnpm test:e2e` で別に実行します。CIでは両方を実行し、`main` の成功したビルドだけをGitHub Pagesへデプロイします。

実行結果はその時点のActionsログ・テスト出力を確認してください。将来の変更後も同じ結果になることを、この文書で保証するものではありません。

## 9. 今後の拡張点

現時点のゲームは、8ステージ・3勝先取または1戦勝負・共通性能・ローカルCPU戦です。次の追加候補として、ステージ差分、アイテム種類、キャラクターごとのしっぽ性能、リプレイ、複数人対戦が考えられます。

オンライン対戦を追加する場合は、通信の追加に加えて、権威を持つシミュレーション、入力の時系列、同期方式、切断時の扱いを設計する必要があります。現在のCPU戦にオンライン機能は含まれていません。
